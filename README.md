# かていきょうし

小学2年生ひとりのための家庭教師アプリ（iPad 用 PWA）。運用費 0 円。

- アプリの中で AI を呼ばない。問題・正誤判定・つまずきの判定・授業計画・ヒントやセリフの選択はすべてルールで動く。
- 先生のセリフ・ヒントは `src/content/` の YAML。Claude Code で作り、おうちの人が確認して入れる。
- 学習記録は iPad の中（IndexedDB）だけに保存する。週1回、書き出して Claude Code で「先生会議」をする（[docs/teacher-meeting.md](docs/teacher-meeting.md)）。

## 今できること（v0.4）
- 授業の流れ：あいさつ（前回の成長を覚えている）→ 気分チェック → ウォームアップ → 復習 → 算数と国語の重点 → 「先生に教えて」 → 子どもが選ぶ問題 → できる問題で終わる → きょうの ノート（新しいシール）→ にがてに もういちど チャレンジ（答えを見た・ヒントをたくさん使った単元を2問ずつ）
- 算数（小2 2学期から）：100をこえる筆算、九九（段・ミックス・□・きまり）、かけ算とたし算・ひき算の文章題、時こく（読む・針を動かす・○分前／後・かかった時間）、かさ、長さ、4けたの数・数直線・大小、表とグラフ、分数、三角形と四角形。1学期の内容はふくしゅう扱い
- 国語：かたかな、漢字の読み・書き、主語と述語、読みとり（ものがたり・せつめい文、たて書き）、反対の言葉・なかまの言葉、助詞、句読点とかぎ、ようすを表す言葉
- 問題の難しさは、その子の習熟に合わせて3段階で変わる
- 間違い方の判定と、原因に合ったヒント3段階 → 答えと、にた問題
- 入力：タップ（すうじパッド）／かく（Apple Pencil・ゆびで手書き。正解した字をその子のお手本として覚える）／とけいの針を指で動かす
- やる気と成長：シールちょう、がくしゅうマップ、先生の見た目をえらぶ、今週のまる、正解の効果音
- 読み上げ：助詞「は・を・へ」や単位・漢字の読みを直して読む（content/readings.yaml）
- 記録を守る：とちゅうでアプリが閉じても、答えた問題のぶんは次に開いたときに反映。授業のおわりはまとめて1回で保存
- おうちの人のページ：今日の数字と連絡帳、今週のグラフ、今週の成長、つまずき（実際の間違いの例つき）、次の予定、スキルマップ（出す／ためす）、記録、設定（教科・時間・声・効果音）、思い出、書き出し。暗証番号をわすれたときの入り方あり

## 開発
```bash
npm install
npm run dev        # http://localhost:5173 （同じWi-FiのiPadからは http://<MacのIP>:5173）
npm test           # ルールと教材の検証
npm run validate   # 教材ファイルだけ検証
npm run build
```

見た目の確認：開発中は `http://localhost:5173/?trial=スキルID`（例 `?trial=jp.reading.story`）で、その単元のおためし画面を直接開けます。

## iPad で使う（GitHub Pages に公開したあと）
1. Safari で公開 URL を開く → 共有ボタン → **ホーム画面に追加**
2. ホーム画面のアイコンから開く（こうすると記録が消されにくい）
3. 先生の声をきれいにする：設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語 → 高品質の声をダウンロード
4. はじめの設定：呼び名・よみ（ひらがな）・暗証番号

記録は iPad の中だけにあるので、月に1回は「記録を書き出す」でバックアップしてください。

## フォルダ
```
src/content/      教材（スキル地図・ヒント・セリフ）← Claude Code で編集
src/domain/       ルール（問題生成・判定・学習者モデル・計画・成長）
src/engine/       授業の進行（状態遷移）
src/db/           iPad 内の保存（Dexie）
src/ui/           画面（kid/ 子ども、parent/ おうちの人）
tests/            ルールと教材の検証
docs/             先生の人物カード、先生会議の手順
```
