# 週1回の先生会議（約15分）

アプリの記録を Claude Code で分析し、プロフィール・来週の方針・教材を更新する。API料金はかからない。

## 手順
1. iPad：おうちの人のページ → 設定 → **記録を書き出す**。AirDrop などで Mac に送る。
2. Mac：このフォルダの `exports/` に置く（`exports/` は Git に入らない）。
3. このフォルダで Claude Code を開き、下の依頼文を貼る。
4. Claude Code が作った提案（`docs/meetings/YYYY-MM-DD.md` と教材ファイルの変更）を読む。
5. 良ければ反映をお願いする。教材を変えたら `npm run validate` が通ることを確認する。
6. 設定の変更（好きなもの・出すスキル・問題数など）は、iPad のおうちの人のページで行う。

## 依頼文（コピーして使う）

```
exports/ にある最新の書き出しファイルを読んで、今週の先生会議をしてください。

参照するもの：
- docs/teacher-card.md（先生の人物カード）
- src/content/skills.yaml（スキル地図と誤解一覧）
- src/content/hints/, src/content/lines.yaml（ヒントとセリフ）

やってほしいこと：
1. 今週の様子のまとめ（学習日数・時間・問題数・ヒントなし正答率の変化、気分チェックの傾向）
2. 成長したこと（根拠となる回答の日時と問題を添えて）
3. つまずきの見直し：
   - ルールで「くり返し」になったものは妥当か
   - 「不明（unknown）」になった間違いに共通する誤解はないか。あれば skills.yaml に誤解を追加し、
     src/domain/math/diagnose.ts の判定と hints にヒントを追加する案を出す
4. 来週の方針（重点スキル、出す／出さないスキル、問題数や時間の調整）を、おうちの人が設定画面で変える形で提案
5. 教材の追加・修正（同じセリフを聞きすぎている場面の言い方を増やす、効きにくかったヒントの書き直し）
6. おうちの人向けの一言（2〜3文）

守ること：
- 提案は docs/meetings/<今日の日付>.md に書く。教材ファイルの変更は、私が OK するまで差分の提案だけにする
- 推測は「今のところ〜のようです」と書き、決めつけない
- 子どもの名前や個人情報をファイルに書かない
- 変更したら npm run validate と npm test を通す
```
